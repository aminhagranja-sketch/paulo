# Download Windows

Baixe [MeuGalinheiro-Windows.zip](https://github.com/aminhagranja-sketch/paulo/raw/refs/heads/main/downloads/MeuGalinheiro-Windows.zip), extraia a pasta inteira e execute `meu_galinheiro.exe`. Mantenha `assets` ao lado do executável.

Este pacote foi compilado para Windows x64 com MinGW no Linux. Sua execução em Windows real ainda não foi verificada. A CI também compila e testa o código nativamente com MSVC.
